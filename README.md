# Лабораторные работы по Express.js (ЛР 1–9)

Готовый комплект проектов по дисциплине «Разработка серверных приложений
и REST API с использованием Express.js».

## Состав

| Папка | Лабораторная работа | Что реализовано |
|-------|---------------------|-----------------|
| `lab1-express-shop` | № 1 | первый сервер, GET-маршруты, текстовые и JSON-ответы |
| `lab2-express-shop` | № 2 | маршрутизация, GET/POST/PUT/PATCH/DELETE |
| `lab3-express-shop` | № 3 | `req.params`, `req.query`, `req.body`, фильтры, CRUD |
| `lab4-express-shop` | № 4 | `express.Router()`, файлы маршрутов по ресурсам |
| `lab5-express-shop` | № 5 | logger, requestTime, checkApiKey, Router-level middleware |
| `lab6-express-shop` | № 6 | routes → controllers → services |
| `lab7-express-shop` | № 7 | полный CRUD товаров и категорий |
| `lab8-express-shop` | № 8 | валидация, AppError, notFound, errorHandler |
| `lab9-shop-admin` | № 9 | админ-панель: frontend + REST API категорий |

ЛР 1–8 — последовательные версии одного проекта `express-shop`.
В каждой следующей папке сохранены возможности предыдущих работ и добавлены
требуемые изменения. ЛР 9 — отдельный проект `shop-admin`.

## Требования

- Node.js 18+ (проверено на Node.js 26);
- npm;
- Visual Studio Code (по желанию);
- браузер или HTTP-клиент (Postman, Thunder Client, curl).

## Быстрый старт

Откройте нужную папку в VS Code и выполните в терминале:

```bash
npm install
npm start
```

Сервер по умолчанию: <http://localhost:3000>

Для разработки с автоперезапуском:

```bash
npm run dev
```

Если порт 3000 занят, его можно переопределить:

```powershell
$env:PORT=4000; npm start
```

## Как открыть всё сразу в VS Code

Дважды щёлкните файл `ExpressJS-Labs.code-workspace` или выполните:

```bash
code ExpressJS-Labs.code-workspace
```

В боковой панели появятся все девять проектов.

## Важные замечания

- Все данные хранятся в памяти процесса. После перезапуска сервера
  изменения (созданные, изменённые и удалённые товары/категории)
  сбрасываются к исходным.
- В ЛР 5 создание товара защищено заголовком `x-api-key: college-demo`.
  В ЛР 6–8 middleware сохранён в проекте, но не подключён к POST, чтобы
  запросы из методички без заголовка работали; как включить защиту,
  написано в README соответствующей работы.
- В каждой папке есть собственный `README.md` с маршрутами, командами
  проверки и пояснениями.
- `node_modules` не входит в архив исходников: выполните `npm install`
  в папке проекта (в этом комплекте зависимости уже установлены).

## Проверка

В README каждой лабораторной работы приведены таблицы маршрутов и примеры
